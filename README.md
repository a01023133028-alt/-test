# 🌱 잡초 사진 퀴즈

대학 잡초 식별 시험(77종) 대비용 개인 공부 사이트입니다.
사진을 랜덤으로 보여주고 **이름·형태적 분류·생활형**을 맞힙니다.
서버·DB·AI 없이 HTML + CSS + 바닐라 JavaScript만으로 동작하고, 기록은 브라우저(localStorage)에 저장됩니다.

## 기능

| 퀴즈 유형 | 설명 |
|---|---|
| 1. 사진 → 이름 쓰기 | 주관식. 띄어쓰기 무시, 괄호 별칭 허용 (`토끼풀(클로버)` → "토끼풀"·"클로버" 모두 정답) |
| 2. 사진 → 4지선다 | 오답 보기를 같은 형태적 분류에서 먼저 뽑아 헷갈리게 출제 |
| 3. 이름 → 분류·생활형 | 객관식 버튼 (사진 없는 잡초도 출제) |
| 4. 실전 모드 | 사진 → 이름 + 분류 + 생활형 한꺼번에 (셋 다 맞아야 정답) |
| 5. 오답만 다시 풀기 | 틀린 뒤 아직 다시 맞히지 못한 잡초만, 1~4 중 원하는 유형으로 |

- 출제 옵션: 문제 수(10 / 20 / 전체), 형태적 분류·생활형 필터, **한 바퀴 모드**(범위 안의 잡초가 한 번씩 다 나올 때까지 중복 없이, 나눠 풀어도 이어짐)
- 풀이 화면: 사진 탭하면 확대, "다른 사진 보기" 힌트(사용 시 표시), 정답 확인 후 이름·분류·생활형·특징·모든 사진, **엔터 키**로 확인 → 다음 (4지선다는 숫자키 1~4)
- 결과: 점수, 틀린 잡초 목록(사진 포함), 틀린 문제만 바로 다시 풀기
- 기록: 잡초별 누적 정답률, 자주 틀리는 잡초 TOP 10, 기록 초기화
- 암기 체크(✅ 암기 탭): 잡초·병해 전체를 사진 카드로 나열하고, 확실히 외운 것을 체크하면 퀴즈에 나오지 않음(홈의 "외운 것 빼고 출제" 스위치로 끄고 켬). 안 외운 것/외운 것 필터, 이름 가리기(눌러서 확인), 정답 화면·도감 상세에서도 바로 체크 가능. 체크는 과목별로 따로 저장되고 기록 초기화와는 별개
- 헷갈리는 쌍(비교 탭): 39쌍(망초·개망초·봄망초처럼 3개 묶음 포함)을 생김새·이름·생활형/분류·키워드별로 묶어 사진과 구분 포인트로 나란히 보기. 쌍마다 사진 보고 맞히기 연습(8문제), 전체 쌍 섞어서 연습(20문제). 쌍 목록은 `data/pairs.json`에서 수정(`kind`, `ids` 2~3개, `a`/`b` 또는 `notes`, `common`)
- 도감: 분류별 / 생활형별로 묶어 사진 카드로 보기, 이름 검색, 카드 누르면 사진 전부 + 정보
- 모바일 우선 큰 버튼, 다크모드(시스템 설정 따름 + 상단 🌙 버튼으로 전환)

## 병해 퀴즈

상단의 **🦠 병해** 버튼(주소 `?s=disease`)으로 병해 사진 퀴즈로 넘어갑니다. **🌱 잡초** 버튼을 누르면 다시 잡초 퀴즈로 돌아옵니다.

- 사진과 **기주**(예: 기주: 배추)를 보고 병명을 맞힙니다.
  - 주관식: "탄저병"처럼 병명만 써도 되고, "배추 탄저병"처럼 기주를 붙여 써도 정답입니다.
  - 바이러스는 약어도 정답입니다. 예: TSWV, TYLCV, CMV
- 4지선다는 같은 기주 → 같은 작물 구분(식량작물·채소·과수·수목) 순으로 헷갈리는 보기를 뽑습니다.
- 도감은 작물별(기주로 다시 묶음), 병원별(곰팡이 병꼴균·자낭균·담자균·불완전균, 세균, 바이러스, 파이토플라스마 — 안에서 작물별로 묶음) 또는 병명별(예: 탄저병 — 배추·포도·사과·고추)로 볼 수 있습니다.
- 기록(정답률·오답 목록·한 바퀴 진행)은 잡초와 따로 저장됩니다.
- 데이터는 `data/diseases.json`(`id`, `name`, `host`, `crop`, `pathogen`, `features`, `images`), 사진은 `images/disease/{3자리 id}/01.jpg`입니다. `pathogen`(병원 종류)은 기주 옆 태그로 정답 화면과 도감에 표시됩니다.

## 실행 방법

### 방법 1. 로컬 서버로 열기 (권장)

폴더에서 아래 명령 중 하나를 실행한 뒤 브라우저에서 `http://localhost:8000` 을 엽니다.

```bash
python -m http.server 8000      # 파이썬이 있을 때 (Windows는 py -m http.server 8000)
npx serve .                     # Node.js가 있을 때
```

VS Code를 쓴다면 **Live Server** 확장으로 `index.html`을 열어도 됩니다.

### 방법 2. index.html 더블클릭

브라우저 보안 정책 때문에 파일로 직접 열면 `data/weeds.json`을 자동으로 읽지 못합니다.
이때는 화면에 나오는 **"weeds.json 파일 선택"** 버튼으로 `data/weeds.json`을 한 번 골라 주세요.
데이터가 브라우저에 저장되어 다음부터는 바로 시작됩니다. (사진은 `images/` 폴더에서 그대로 불러옵니다.)

> weeds.json을 수정했다면 다시 골라야 합니다: 홈 화면 아래 **"파일 다시 선택"** 또는 기록 화면의 **"저장된 weeds.json 지우기"**.

## 폴더 구조

```
index.html          화면 틀
css/style.css       디자인 (분류·생활형 색상, 다크모드)
js/subject.js       과목(잡초/병해) 설정: 문구·데이터 파일·분류 기준
js/storage.js       localStorage 저장 (정답률, 오답 목록, 한 바퀴 진행)
js/grading.js       주관식 채점 (띄어쓰기 무시, 괄호 별칭)
js/data.js          weeds.json 불러오기·검사
js/quiz.js          출제·채점 로직
js/ui.js            공용 화면 조각 (사진 확대, 모달)
js/app.js           화면 전환과 각 화면
data/weeds.json     잡초 데이터 (77종)
data/diseases.json  병해 데이터 (63개)
data/pairs.json     헷갈리는 쌍 목록과 구분 포인트
images/001/01.jpg   잡초별 사진 폴더 (번호 3자리)
```

## 데이터 형식 (`data/weeds.json`)

```json
[
  {
    "id": 1,
    "name": "개기장",
    "morph": "화본과",
    "life": "하계일년생",
    "features": "가는 이삭이 늘어짐",
    "images": ["images/001/01.jpg", "images/001/02.jpg"]
  }
]
```

| 필드 | 값 |
|---|---|
| `id` | 번호 (겹치면 안 됨) |
| `name` | 이름. 괄호 안은 별칭으로 인정 — `토끼풀(클로버)`, `여뀌(역귀)` |
| `morph` | `화본과` / `방동사니과` / `광엽잡초` 중 하나 |
| `life` | `하계일년생` / `동계일년생` / `월년생` / `다년생` 중 하나 |
| `features` | 특징 메모 (비워도 됨, 줄바꿈은 `\n`) |
| `images` | 사진 경로 목록. **비어 있으면 사진 문제에서 자동 제외** |

잘못된 값이 있으면 홈 화면 아래에 "데이터 경고"로 표시됩니다.

## 사진 추가 방법

1. 사진을 그 잡초 번호 폴더에 넣습니다. 번호는 3자리입니다.
   예) 1번 개기장의 두 번째 사진 → `images/001/02.jpg`
2. `data/weeds.json`에서 그 잡초의 `images` 배열에 경로를 추가합니다.
   ```json
   "images": ["images/001/01.jpg", "images/001/02.jpg"]
   ```
3. 끝. 장수 제한은 없고, 퀴즈에서는 그중 한 장이 랜덤으로 나옵니다.

팁: 사진은 가로 1200px 이하 JPG로 줄이면 휴대폰에서 빨리 뜹니다. 파일 이름은 영어·숫자로 쓰는 것이 안전합니다.

## 배포 방법

빌드 과정이 없으므로 폴더 그대로 올리면 됩니다.

### GitHub Pages

1. 이 폴더를 GitHub 저장소에 올립니다 (`index.html`이 저장소 최상위에 있어야 함).
2. 저장소 **Settings → Pages** → Source를 **Deploy from a branch**, 브랜치 `main` / 폴더 `/(root)`로 저장.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

### Netlify

1. <https://app.netlify.com/drop> 에 이 폴더를 통째로 끌어다 놓습니다.
2. 바로 주소가 생깁니다. (GitHub 저장소를 연결하면 push할 때마다 자동 배포 — 빌드 명령은 비우고, 배포 폴더는 `/`)

> 기록(localStorage)은 **기기·브라우저·주소별로** 따로 저장됩니다. 휴대폰과 PC의 기록은 공유되지 않습니다.

## 참고: 현재 데이터와 사진 출처

- 77종 목록(번호·이름·분류·생활형)은 「잡초 77종 사진 분류집」 PDF에서 가져왔습니다.
- 각 잡초의 `01.jpg`(일부는 `02~04.jpg`까지)는 손글씨 없는 사진 PDF에서 가져온 사진입니다.
- 그 뒤 번호의 사진(총 214장)은 시험에 다른 모습의 사진이 나올 것에 대비해 [iNaturalist](https://www.inaturalist.org)에서 추가했습니다.
  - 전문가 동정을 거친 **연구 등급(Research Grade)** 관찰만, 한국·동아시아 관찰 우선, 계절(새싹·꽃·열매)이 섞이도록 골랐습니다.
  - 라이선스는 CC0 / CC-BY / CC-BY-NC / CC-BY-SA / CC-BY-NC-SA 입니다. 촬영자·라이선스·원본 링크는 `data/credits.json`에 있고, 사이트에서 사진을 크게 보면 위쪽에 표시됩니다.
  - CC-BY-NC 사진이 많으므로 **비상업적 용도(개인 공부)로만** 사용하세요.
  - iNaturalist에 구분된 기록이 없는 **물피·나도겨풀**과 기록이 적은 **올방개**는 사진이 적습니다.
- `features`(특징)는 「잡초 77종 암기노트」의 카드 특징(슬라이드 판서)과 헷갈리는 쌍·키워드 내용으로 채웠습니다. 강아지풀·좀명아주는 노트에 특징이 없어 비어 있습니다.
- 병해 63개의 사진과 기주는 병해 사진 PDF, 병명은 손글씨 답안표에서 가져왔습니다. 사진 위의 문제 번호와 주황 띠는 지우고, 증상을 가리키는 화살표는 남겼습니다. 병원(`pathogen`)은 답안표에 비어 있어 조사해 채웠습니다. 곰팡이는 수업 기준 5분류(병꼴균·접합균·자낭균·담자균·불완전균)로 나눴습니다. 노균병·역병(유주자를 만드는 편모균류)과 배추 뿌리혹병은 병꼴균(편모균류)에, 불완전세대 학명으로 부르는 균은 불완전균에 넣었습니다. 감자 더뎅이병은 "세균(방선균)"으로 표시했습니다. 수업 기준과 다르면 `data/diseases.json`에서 고치면 됩니다.
- 병해 추가 사진 86장(27개 병해, 총 149장)은 iNaturalist 관찰 사진과 PlantVillage 데이터셋(CC0, 실험실에서 찍은 잎 사진)에서 골랐습니다. 기주와 증상이 원본 사진과 맞는 것만 넣었고, 현미경·배양 사진이나 다른 작물 사진은 뺐습니다. 나머지 36개는 공개 사진이 없거나 다른 작물 사진뿐이라 원본 1장만 있습니다.
